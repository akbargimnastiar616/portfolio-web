# Muhammad Akbar Gimnastiar - Professional Portfolio

An executive-level, high-impact single-page portfolio tailored for corporate recruiters in Banking, BUMN, and Fintech sectors.

## 🚀 Live Preview & Deployment

### Quick Deploy to Netlify
1. **Option A: Netlify Drop (Zero Setup)**
   - Go to [Netlify Drop](https://app.netlify.com/drop).
   - Drag and drop the `akbar-portfolio` folder directly into the browser upload zone.
   - Your site will be live on a secure HTTPS URL in under 30 seconds!

2. **Option B: GitHub / Git Repository**
   - Push this folder to a GitHub repository.
   - Connect the repo to Netlify.
   - Build command: *(leave empty)*
   - Publish directory: `.`

3. **Local Development / Preview**
   - Simply double click `index.html` to open in any browser, or run:
     ```bash
     npx serve .
     ```
